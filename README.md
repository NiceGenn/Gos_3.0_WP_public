# Гос 3.0 — промо-лендинг темы

Промо WordPress-темы «Гос 3.0» для официального сайта учреждения.
Обновлено под **v2.17.0**: семь разделов панели, проверка готовности сайта,
копия настроек с предпросмотром и откатом, архив PDF с выбором текущего,
улучшения приёмной и клавиатурного управления.

Сайт: <https://nicegenn.github.io/Gos_3.0_WP_public/>
Репозиторий: <https://github.com/NiceGenn/Gos_3.0_WP_public>

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/docs`.
`docs/index.html` — самодостаточная страница со встроенными CSS, JS и снимками.
`docs/.nojekyll` отключает Jekyll. Изменение файла в `main` запускает публикацию
при указанной настройке Pages.

Редактируемые исходники находятся в основном проекте: `sources/landing/`.
Сборка: `bash tools/build-landing.sh`; версия промо — **1.1**.
В этот публичный репозиторий переносится только собранный `docs/index.html`.
Исходники WordPress-темы, её ZIP, секреты и внутренняя память сюда не копируются.
