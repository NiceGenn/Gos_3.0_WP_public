# Гос 3.0 — промо-лендинг темы

Промо-страница WordPress-темы **«Гос 3.0»** — готового решения для официального
сайта государственного учреждения: новости, документы, руководство,
интернет-приёмная, версия для слабовидящих (ГОСТ Р 52872), умная боковая
колонка, 6 цветовых схем и панель-дашборд со всеми настройками сайта. Прошла
аудит безопасности, работает без внешних CDN.

## Лендинг

Одностраничный лендинг — самодостаточный `docs/index.html` (все стили и
изображения встроены, внешних запросов нет).

**Опубликован через GitHub Pages:** <https://nicegenn.github.io/gos_3.0_wp_public/>

### Как публикуется

GitHub Pages раздаёт содержимое папки `docs/` из ветки `main`:

1. `Settings → Pages` этого репозитория.
2. **Source** → «Deploy from a branch».
3. **Branch** → `main`, папка **`/docs`** → **Save**.

Файл `docs/.nojekyll` отключает обработку Jekyll. Чтобы обновить лендинг —
замените `docs/index.html` и запушьте в `main`; Pages пересоберётся сам.
